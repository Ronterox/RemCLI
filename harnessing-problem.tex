		\newline\newline \textbf{Requirements for a good agent:}
		\begin{enumerate}
			\item Good instruction following of simple requests
			\item Decent consistency of answers for the same input
			\item Visualize thinking process, and reasoning model
			\item Be able to do function calling, for MCP
		\end{enumerate}
	\item Find a general model that can be used for all the above,
	without consuming much of your GPU resources for smoke testing
	\end{enumerate}
